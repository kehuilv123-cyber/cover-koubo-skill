# 创作案例与数据口径

记录日期：2026-07-19。材料来源：作者保存的《抖音破万作品播放量记录_从楚怡工匠开始》和阶段性复盘报告，均以当时账号主页截图为基础。此处为历史整理数据，并非本次实时读取平台后台。

- 7 条作品中 4 条破万，占比 4/7，约 57%。
- 四条页面显示值分别为 10.5 万、11.3 万、3.0 万、19.0 万，合计 43.8 万；该合计不是全部 7 条的总播放量。
- 其中 3 条达到 10 万级；单条最高 19.0 万。
- 页面缩写值不是后台精确次数。未包含原始截图或其他人物的私人信息。

案例用于形成选题、开头、拍摄、封面和复盘规则。缺少逐条版本使用记录与同口径前后对照，因此不将所有历史作品称为当前 Skill 直接生成，也不把这些数字表述为 Skill 导致的增量。两秒跳出率与完播率尚无可公开的前后对照数值。
