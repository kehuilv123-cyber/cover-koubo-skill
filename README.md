# 抖音口播 Skill · 早期闭环独立版

作者：**吕柯辉**。从一个灵感，到能拍摄的口播，再用发布后的数据决定下一条怎么改。

```text
灵感 → 选题定位 → 前两秒开头 → 口播文案 → 拍摄清单
     → 封面制作 → 发布前质检 → 24 小时复盘 → 下一条迭代
```

这是个人原创工作流的早期闭环版本，按作者要求单独发布。保留当时的账号定位、制片流程、两秒留存标准、封面标准和复盘规则；没有混入后来的商业工作台、cheat-on-content 或其他第三方 Skill 包。文档由作者在 AI 协作中形成；不把“原创工作流”描述为未经 AI 辅助逐字手写。

## 适合做什么

- 把零散灵感整理成选题、标题和可拍摄口播。
- 对比痛点、悬念、结果三种开头。
- 规划 A-roll / B-roll、场景、光线和封面照片。
- 根据真实照片制作与视频承诺一致的封面。
- 用播放、留存、互动、关注等数据复盘，输出下一条的具体修改。

当前版本不会自动剪辑、发布抖音或读取平台后台数据。封面图片生成需要运行环境提供相应工具；没有工具时不能声称已生成图片。

## 安装

```bash
git clone https://github.com/kehuilv123-cyber/douyin-koubo-skill.git
```

将 `skills/douyin-cover-maker` 文件夹复制到客户端的 Skill 目录。Codex 通常为 `$CODEX_HOME/skills` 或用户目录的 `.codex/skills`，其他客户端以自身配置为准。

**保留历史 Skill 名 `douyin-cover-maker`。如果已经安装新版同名 Skill，请先备份，或在独立客户端配置中使用，避免覆盖。** 仓库名突出口播闭环，历史名字不代表它只做封面。
