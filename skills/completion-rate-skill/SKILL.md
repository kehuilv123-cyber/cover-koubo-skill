# 完播率与正文节奏优化

读取 `references/completion-rate-standards.md`。输入为原口播、视频时长和已有留存数据；数据不足时先做内容审查，不虚构掉点。

按开头承诺、论证/故事推进、证据兑现、结尾四段检查。指出优先问题，输出逐段修改理由、完整改稿、时间预算和拍摄提示。保留用户观点，不用无关悬念拖延答案。

复盘时把完播率、平均播放时长和视频时长分开记录。交付一个可检验的下一条结构调整。缺少同口径前后数据时不写“完播提升了 X%”。此包的完播规则来自早期复盘标准的整理，不代表历史上已经存在一个独立完播 Skill。
