# 前两秒留存优化

读取 `references/two-second-retention-script-standards.md`。聚焦观众是否愿意停下，不默认重写整条视频或制作封面。

1. 从真实内容找出需求、共鸣、稀缺体验或相关热点，明确第一句话承诺。
2. 输出第一帧、第一句话、核心字幕、声音建议，以及痛点/悬念/结果三种开头。必须在正文兑现，不能为了钩子补造事实。
3. 删除无意义问候与铺垫，保留必要上下文。输出一个推荐版本并解释选择依据。
4. 有数据时记录播放样本量、两秒跳出率、统计窗口和视频时长。定义以平台实际字段为准；未知不填零。
5. 比较相近题材、时长、流量来源和相同统计窗口；不同发布视频不当成随机 A/B 实验。每轮优先改变一个开头变量，同时观察完播率，避免仅靠误导式开头留人。

没有数据时交付开头方案和待测指标，不声称已降低跳出率。
