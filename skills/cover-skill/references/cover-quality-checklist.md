# Cover Quality Checklist

## Primary Standards

Use these standards first. They are mandatory for this user's Douyin cover workflow.

| Standard | What it means | Pass standard |
| --- | --- | --- |
| Matching shoot photo | Cover uses the corresponding video's real shoot photo, frame grab, or requested reshoot | Viewer can feel the cover belongs to this exact video |
| Complete theme | Person, scene, topic, and click reason form one complete message | Viewer understands the video promise without reading the caption |
| Clear bright base image | The base image is sharp, bright, and usable for text overlay | Face/person is clear; title area is clean; image is not dark or noisy |
| Strong personal appeal | The creator has expression, emotion, and presence | Pose/expression matches the video and makes the creator memorable |
| Concise clear copy | Cover copy is short, concrete, and instantly readable | Main title is preferably 6-12 Chinese characters and no more than 2 lines |
| Ordered hierarchy | The layout guides the eye in the right order | Person, main title, scene, subtitle have clear hierarchy |
| Audience memory | The cover helps viewers remember the creator/topic/series | It reinforces personal IP, content pillar, or recurring visual cue |

## Ratio Check

The cover should use 3:4 or 4:3 unless the user explicitly asks otherwise.

Pass standard:

- 3:4 is used for person-first, portrait, knowledge/education, or campus daily covers.
- 4:3 is used for wider campus/travel/desktop/comparison scenes.
- The selected ratio supports the theme instead of cropping away the person or scene.

## Text Overlay Check

Generate Chinese cover text in the image workflow first, then use the manual overlay backup whenever the generated text is inaccurate.

Pass standard:

- Main title is readable at phone-feed size.
- Text does not cover the face.
- Text stays inside safe margins.
- Only 1-2 keywords are highlighted.
- Subtitle is smaller and not competing with the main title.
- If the image-generation tool rendered Chinese text, inspect and correct any malformed characters manually.

## Pass/Fail Checks

Mark each as pass, revise, or fail.

| Check | Pass standard |
| --- | --- |
| Source photo | Uses this video's real shoot photo/frame grab or a clearly requested reshoot |
| Creator likeness | AI did not change the creator into a different person |
| Outfit/scene match | Outfit and setting still match the video |
| Ratio | Uses 3:4 or 4:3, with no important person/title cropping |
| Complete theme | Person, scene, topic, and click reason are clear |
| Base image | Bright, sharp, clean, and title-safe |
| Personal appeal | Expression/pose has emotion and creator presence |
| Copy clarity | Main title is concise, concrete, and readable |
| Manual text | Chinese text is manually overlaid or verified after generation |
| Layout hierarchy | Main visual order is person/scene -> title -> supporting detail |
| Memory | Strengthens creator recognition or content-series impression |
| Personal image | Face or personal figure is clear and not blocked |
| Content signal | Viewer can tell whether it is knowledge, campus, or travel |
| Main title | Readable at phone-feed size |
| Hook | Gives a clear reason to click |
| Visual hierarchy | Person, title, and background do not fight |
| Authenticity | Looks like the real creator's content, not a generic ad |
| Match | Cover promise matches the actual video |
| Privacy | Private messages, names, scores, and school details are blurred or removed |
| Quality | No blurry face, distorted limbs, messy text, cheap stickers, or excessive filters |

## Scoring Rubric

Score from 1-5:

- Source photo match: does it belong to this video?
- Theme completeness: is the cover message complete?
- Base image quality: is it clear and bright?
- Personal appeal: does the creator have strong presence?
- Copy clarity: is the text concise and instantly readable?
- Layout hierarchy: is the visual order clear?
- Audience impression: does it strengthen memory of the creator/topic?

Recommended decision:

- 32-35: publishable.
- 27-31: revise small details.
- 21-26: redesign direction.
- 20 or lower: do not publish.

## Common Fixes

If title is hard to read:

- Shorten the title.
- Move text to a cleaner area.
- Add contrast between text and background.
- Use two-line hierarchy.

If person is weak:

- Use a closer portrait.
- Increase face size.
- Choose a clearer expression or pose.
- Avoid covering the face with text.

If AI changed the creator too much:

- Re-run with stricter wording to preserve face, outfit, and scene.
- Use the original photo with manual layout instead of heavy regeneration.
- Ask for a new cover photo if the original source is too weak.

If cover feels generic:

- Use a photo from the actual video shoot.
- Add a real campus/travel/desk scene.
- Use a more personal title.
- Add a detail from the actual video.

If cover overpromises:

- Replace extreme claims with accurate benefits.
- Use the strongest real line from the video.
- Make the title match the first 5 seconds of content.

If the theme feels incomplete:

- Add a clearer scene signal.
- Add a more specific title.
- Use a frame where the creator and topic appear together.
- Replace decorative background with a meaningful content scene.

If the base image is dark or muddy:

- Choose a brighter screenshot or reshoot a cover photo.
- Move to window light or outdoor shade.
- Simplify the background behind the title.
- Avoid strong filters before title design.

If the cover does not strengthen memory:

- Increase the creator's face or body presence.
- Reuse a consistent color, title style, or content-series cue.
- Add a recognizable campus, desk, or travel symbol.
- Make the title sound more like the creator's real content voice.
