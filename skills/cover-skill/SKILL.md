# 短视频封面制作

输入为视频主题、标题、内容承诺、目标观众和用户有权使用的实拍照片或视频帧。

1. 按 `references/cover-production-standards.md` 和 `references/cover-visual-guidelines.md` 提炼主标题与画面层级。
2. 使用 `references/cover-prompt-patterns.md` 形成构图、文字安全区与图片生成方案。用户请求成图且环境有图片生成能力时直接生成，不止于提示词；无生成能力时说明当前交付为方案。
3. 参考图先查看再使用；保留真实人物特征。不要把无权使用的图片当自有素材。
4. 按 `references/cover-quality-checklist.md` 检查中文准确性、手机可读性、人物与文字层级及封面承诺是否符合视频。
5. 输出成品或方案、质检结果和一项必要修改。不自动发布，也不承诺点击率提升。
