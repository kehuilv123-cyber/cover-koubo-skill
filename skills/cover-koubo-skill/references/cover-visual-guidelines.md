# Cover Visual Guidelines

## Universal Rules

- Use 3:4 or 4:3 ratio unless the user explicitly asks for another ratio.
- Use 3:4 for person-first portrait covers; use 4:3 for wider scene, travel, desktop, or comparison covers.
- Ensure the cover theme is complete: person, scene, topic, and click reason should work together.
- Start from a clear and bright base image; do not rely on later editing to rescue a weak screenshot.
- Make the person emotionally present: expression, posture, or gesture should match the video.
- Keep copy concise and readable; do not overload the cover with script-like text.
- Arrange layout by priority: person/scene first, main title second, supporting detail third.
- Add a recognizable memory cue: face, campus, desk, travel item, repeated color, or title rhythm.
- Prioritize a real human image from the corresponding video shoot: face, half-body, side profile, back view, or recognizable personal silhouette.
- Use the current video's actual photo/frame as the base whenever available; use generated imagery only to polish composition, light, background, and title space.
- Use one initial image-generation prompt by default to create or polish the final cover and render the exact Chinese title/subtitle. Make a targeted follow-up edit only when one clear defect is visible, and keep a manual overlay backup when Chinese text accuracy matters.
- Main title should be readable within 3 seconds.
- Use one strong title area with clear blank space.
- Keep person, title, and background in separate visual layers.
- Do not let text cover the face.
- Use real campus/travel/desk scenes when available.

## Knowledge/Education Covers

Goal: credible, clear, useful.

Composition:

- Person on left or right, title on the opposite side.
- Desk, laptop, library, classroom, or clean wall background.
- Optional visual elements: phone screen, notebook, keyword card.

Title patterns:

- 大学生必会 AI
- 3 分钟做封面
- 学习效率翻倍
- 别再乱做笔记
- 普通人也能做到

Colors:

- Base: white, dark gray, light blue, green.
- Highlight: yellow or bright blue.
- Avoid: large red-black warning style unless it is a warning topic.

## Campus Covers

Goal: real, youthful, relatable.

Composition:

- Person naturally appears in a campus setting.
- Show recognizable campus context: road, library, classroom, playground.
- Title can sound like an observation or diary line.

Title patterns:

- 大学校园的一天
- 原来大学是这样
- 今天去图书馆
- 校园里的一件小事
- 大学生真实日常

Colors:

- Green, white, light blue, warm yellow.
- Keep natural light and campus texture.
- Avoid over-polished commercial effects.

## Travel Vlog Covers

Goal: atmosphere, location, emotion.

Composition:

- Person and place both need to appear.
- Back view, side profile, walking pose, or looking back works well.
- Use the location as a story signal, not only as decoration.

Title patterns:

- 一个人去旅行
- 周末逃离校园
- 这座城市很浪漫
- 我在路上想明白了
- 去看一场日落

Colors:

- Warm orange, sky blue, city gray, film green.
- Adapt to each location.
- Night covers need high text contrast.

## Variant Concepts

When the user explicitly requests concepts or variants, generate:

1. Stable version: clearest and safest value expression.
2. Click version: stronger hook, contrast, result, or curiosity.
3. IP version: most recognizable personal image.

Optional:

- Atmosphere version for campus/travel.
- Result-comparison version for knowledge/education.
